# TV só do ADM — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/tv` e o quadro da API passam a exigir sessão de ADM; o uso não muda (o ADM abre "Abrir TV ↗" no notebook já logado e projeta).

**Architecture:** `GET /board` passa a exigir ADM e perde o cache público (resposta privada, `no-store`). No site, a TV ao vivo consulta o quadro pelo cliente autenticado (o mesmo token da aba do painel, que fica no armazenamento do navegador); sem sessão de ADM, mostra "Entre como ADM para ver a TV" com o link para `/conta`. `/tv?demo` continua sem login (dados fictícios).

**Spec:** `docs/superpowers/specs/2026-10-26-ajustes-testes-design.md` (item 8).

## Global Constraints

- Sem sessão: 401; jogador ou juiz: 403; ADM: 200 com `Cache-Control: no-store`.
- Nenhum recurso novo; custo: a TV consulta a Lambda a cada 5 s (dentro do gratuito).
- `npm run check` passa ao fim de cada tarefa.

## Tasks

1. **API:** teste (401, 403, ADM 200 sem cache público) → `GET /board` com `requireAdmin`; testes antigos passam a usar o token do ADM. Commit `feat(api): quadro da TV só para o ADM`.
2. **Site:** `api.board()`; `LiveTv` recebe a função de carga do cliente autenticado; 401/403 → aviso com link para `/conta`; `main.tsx` monta a TV depois da sessão. `npm run check`, build, screenshot de `/tv` sem login. Commit `feat(web): TV só com sessão de ADM`.
3. **AWS, README, PR** empilhado sobre a entrega 7.
